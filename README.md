# Retail Sales Data Cleaning using Power Query

## Project Overview
This project focuses on cleaning and transforming a raw retail sales dataset using Power Query.

The dataset contained inconsistent formatting, duplicate records, unnecessary data, and messy values that required proper cleaning before analysis.

## Tools Used
- Microsoft Excel
- Power Query

## Data Cleaning Tasks
- Removed duplicate values
- Cleaned unnecessary data
- Standardized formatting
- Fixed inconsistent values
- Prepared analysis-ready dataset

## Outcome
The final cleaned dataset became more structured, organized, and analysis-ready.

## Dataset Source
Dataset downloaded from Kaggle.
